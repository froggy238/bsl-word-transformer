SignBank label quality

The cross-corpus set was curated from a 103-row gloss map; 76 clips match the vocabulary keyword exactly. Four words have no same-gloss SignBank entry (stop→FINISH, today→NOW, need→WANT, goodbye→WAVE-HAND) and mostly fail, as expected.

Validation and rigour

Model selection used a 50-clip validation split only (one clip per word); the selection rule was frozen before any test clip was scored. Values are mean ± population standard deviation over seeds 42–44, with the best run in parentheses.
